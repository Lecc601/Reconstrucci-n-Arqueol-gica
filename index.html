Secuencia Conceptual Aplicada

Pieza Arqueológica → Puntos de Control Pᵢ=(Xᵢ,Yᵢ) → Sistema Tridiagonal → Spline Cúbico → Reconstrucción Digital Animada.

a) Spline Cúbico Paramétrico (Activo para perfiles verticales) Recomendado

Permite reconstruir bordes cerámicos que curvan hacia adentro y hacia afuera sin restricción de función y(x):

Xᵢ(t) = aₓ,ᵢ + bₓ,ᵢ(t - tᵢ) + cₓ,ᵢ(t - tᵢ)² + dₓ,ᵢ(t - tᵢ)³
Yᵢ(t) = aᵧ,ᵢ + bᵧ,ᵢ(t - tᵢ) + cᵧ,ᵢ(t - tᵢ)² + dᵧ,ᵢ(t - tᵢ)³
b) Spline Cúbico Explícito

Expresado tramo a tramo cuando las coordenadas están ordenadas de forma estrictamente monótona:

Sᵢ(x) = aᵢ + bᵢ(x - xᵢ) + cᵢ(x - xᵢ)² + dᵢ(x - xᵢ)³

Condiciones de Continuidad Garantizadas

C⁰
Continuidad de Posición: Los tramos coinciden exactamente en cada nodo interior: Sᵢ(tᵢ₊₁) = Sᵢ₊₁(tᵢ₊₁) = Pᵢ₊₁
C¹
Continuidad de Pendiente (1ra Derivada): Transición suave sin esquinas ni picos bruscos en las uniones: S'ᵢ(tᵢ₊₁) = S'ᵢ₊₁(tᵢ₊₁)
C²
Continuidad de Curvatura (2da Derivada): Inflexión continua y frontera natural libre: S''ᵢ(tᵢ₊₁) = S''ᵢ₊₁(tᵢ₊₁), con S''(t₀) = S''(tₙ) = 0.

Algoritmo de Resolución de Splines Cúbicos Naturales

Fragmento clave empleado en esta aplicación para calcular coeficientes y animar la curva 

// 1. Cálculo de coeficientes del Spline Cúbico Natural: S_i(t) = a_i + b_i*dt + c_i*dt^2 + d_i*dt^3
function solveNaturalCubicSpline(t, y) {
    const n = y.length - 1;
    const h = [], alpha = new Array(n).fill(0);
    const a = [...y], b = new Array(n), c = new Array(n + 1).fill(0), d = new Array(n);

    // Paso h_i de cada subintervalo [t_i, t_{i+1}]
    for (let i = 0; i < n; i++) h.push(t[i + 1] - t[i]);

    // Construcción del sistema tridiagonal para garantizar continuidad C0, C1 y C2
    for (let i = 1; i < n; i++) {
        alpha[i] = (3 / h[i]) * (a[i + 1] - a[i]) - (3 / h[i - 1]) * (a[i] - a[i - 1]);
    }

    // Algoritmo de Thomas (Eliminación Gaussiana Tridiagonal)
    const l = new Array(n + 1).fill(1), mu = new Array(n + 1).fill(0), z = new Array(n + 1).fill(0);
    for (let i = 1; i < n; i++) {
        l[i] = 2 * (t[i + 1] - t[i - 1]) - h[i - 1] * mu[i - 1];
        mu[i] = h[i] / l[i];
        z[i] = (alpha[i] - h[i - 1] * z[i - 1]) / l[i];
    }

    // Sustitución regresiva para hallar c_i, b_i y d_i
    for (let j = n - 1; j >= 0; j--) {
        c[j] = z[j] - mu[j] * c[j + 1];
        b[j] = (a[j + 1] - a[j]) / h[j] - h[j] * (c[j + 1] + 2 * c[j]) / 3;
        d[j] = (c[j + 1] - c[j]) / (3 * h[j]);
    }
    return { a, b, c, d, t };
}

// 2. Evaluación Paramétrica (X_i(t), Y_i(t)) para generar la animación continua
function evaluateParametricSpline(splineX, splineY, i, tVal) {
    const dt = tVal - splineX.t[i];
    const x = splineX.a[i] + splineX.b[i]*dt + splineX.c[i]*dt*dt + splineX.d[i]*dt*dt*dt;
    const y = splineY.a[i] + splineY.b[i]*dt + splineY.c[i]*dt*dt + splineY.d[i]*dt*dt*dt;
    return { x, y };
}
